- 当前验收环境只有一台可用物理屏。两个真实 WPF 窗口参加受控拓扑测试。实体双屏拔插、实际混合 DPI 和设备重排仍需现场测试。
- 普通和当前可见的系统桌面图标共用 Explorer 的实时视图。Windows 桌面图标设置提供系统图标的逐项控制。真实 Explorer 的显隐和重启需要经过确认的隔离会话。当前证据包括真实 Explorer 只读检查、隔离窗口显隐和受控恢复状态机。
- 登录启动在当前用户范围注册。真实 Windows 注销后重新登录及企业启动策略下的表现留待现场测试。
- 玻璃模糊作用于 Dock 自绘材质。独占全屏第三方游戏、实际视频播放器全屏及特殊多屏前台切换仍需设备复测。
- 地图拖动、拖放及快捷键分别使用应用逻辑与 Windows 注册探针验收。实体输入和系统原生 OLE 链路有待覆盖。
- 双 Dock 持续运行实测覆盖了十分钟。过夜和长期硬件组合有待复测。
- 此交付未做 Authenticode 代码签名。可比对随包 SHA-256 校验值。
