## 范围与顺序

1. 记录仓库和工具链现场，固定阶段验收口径。
2. 在 `prototypes/` 下建立独立窗口、输入和 Shell 原型。先执行受控窗口、几何与系统注册验证。Shell 先只读探测，并记录会话、窗口归属、可见性和错误码。

## 验收矩阵

| 编号 | 验证项 | 步骤与通过判据 |
| --- | --- | --- |
| P0-01 | WPF 透明窗口 | 构建运行无边框 WPF 窗口，记录 WPF 和 HWND 样式、渲染与可见性，分别观察透明区域和内容的点击命中，确认不出现在任务栏。动画期间的命中单列。 |
| P0-02 | 焦点与显示 | 在已有前台窗口时运行透明窗 Show/Hide，记录前台 HWND 和原型 HWND，原前台保持、原型不激活。稳定的前台基准是通过前提。 |
| P0-03 | 多屏及 DPI | 枚举物理边界、工作区和 DPI，检查以显示器原点换算 DIP。受控覆盖 100/125/150/200% 和负坐标。双屏混合 DPI、跨屏移动、主屏切换、分辨率变化和热插拔需要实屏分别验证。 |
| P0-04 | 鼠标热区 | 对边界、偏移、多个热区、进入、退出、重新进入、触发和收起延迟做可复现检查。真实鼠标采样需另外证实越界不触发、连续命中才触发。 |
| P0-05 | 最大化窗口 | 对普通、最大化窗口记录 `IsZoomed`、窗口与工作区边界和窗口样式，最大化不与普通或无边框全屏混淆。第三方窗口和按屏判定分别验证。 |
| P0-06 | 全屏候选 | 比较填满工作区与填满显示器的窗口，记录边界、样式、DWM 状态。无边框全屏候选判定与视频、游戏、独占全屏验证分别记账，未知状态默认不自动呼出。 |
| P0-07 | 桌面图标只读识别 | 查询 Shell 窗口和实际图标视图的归属、可见性、同会话身份，记录错误和歧义。仅观察结构与状态。 |
| P0-08 | 桌面图标隐藏与恢复 | 获确认后记录初始状态、仅切换显示、观察结果、恢复并复核。按全体、普通、系统范围区分。隔离环境复测手动更改、异常退出、多屏与 Explorer 重启，并确认无文件改动。 |
| P0-09 | 全局快捷键 | 注册临时组合键，验证第二所有者冲突并记录 Win32 错误码，实际按键产生 `WM_HOTKEY`，注销后可重新注册并释放。 |
| P0-10 | 空闲性能 | Release 原型预热后采样至少 30 秒，记录进程 CPU 时间差、采样时长、逻辑核心数、Working Set 和 Private Bytes。P0 初筛采用整机平均 CPU ≤ 1% 和单个原型 Working Set ≤ 150 MiB，最终预算由完整场景另行验证。 |

## 风险与预备方案

| 风险 | 本阶段处理 |
| --- | --- |
| Explorer 窗口结构、所有权与恢复不稳定 | 回避固定句柄和无条件反向恢复。状态有歧义时禁用自动修改，提供系统手动入口。 |
| 普通窗口覆盖全屏与独占呈现难以区分 | 同时采集前台、样式、边界和 DWM 信号。对不确定场景禁止热区自动呼出。 |
| DPI 虚拟化与负坐标 | 声明 Per-Monitor V2，以物理像素统一屏幕和热区坐标，每个窗口只在边界转换 DIP。 |
| 透明窗口输入和空闲开销 | 检查原生不激活展示及透明区命中。性能或命中不达预期时，先缩小绘制面并关闭动画。 |
| 交互桌面或硬件不足 | 记录真实会话限制及复测步骤。受控用例不能替代实屏、实际应用或 Explorer 重启验证。 |
