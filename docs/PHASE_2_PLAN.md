# Desktop Dock 阶段 2 计划

P2 从 P1 提交 `af1be9b` 开始，沿用 Windows 11、WPF、Per-Monitor V2 和本地 MCP。先实现纯状态机与热区几何，再接入 Windows 窗口检测、快捷键及应用窗口，最后以独立配置执行自动回归、实机探针与性能采样。

## 改动边界

1. 默认常驻。自动隐藏由状态机驱动真实窗口显隐，热区本身不创建可见窗口。普通呼出、临时显示、锁定显示与手动收起分别记录。锁定阻止鼠标离开的自动收起，外部点击、Esc 和手动命令可以收起。Esc 优先处理已打开的菜单或面板。
2. 使用屏幕物理像素进行鼠标与热区命中，按该屏缩放换算厚度与偏移。起止按边缘长度百分比保存。每屏可保存多个热区，同一位置按列表顺序命中。P2 保留一个 Dock，热区呼出时移到触发屏，停靠方向沿用 Dock 设置。
3. 窗口避让结合 Win32 窗口状态、样式、DWM 可见边界、显示器归属和 Windows Shell 全屏信号。未知状态阻止自动呼出。快捷键可主动显示，显示过程保留原前台焦点。应用例外使用完整可执行文件路径。
4. 快捷键使用专用消息窗口。验证重复和系统注册错误，失败保留原设置，退出释放绑定。配置版本升至 2，读取 P1 版本 1，首次成功改写时保留原配置备份。
5. MCP 使用独立配置、受控时钟和应用内事件路径。真实 Win32 观察和受控窗口使用单独探针。记录硬件、应用和系统行为差异。

## 验收矩阵

| 项目 | 通过判据 |
| --- | --- |
| P2-01 模式与隐藏 | 常驻可见。AutoHide 启动后窗口不可见，没有边缘残留。手动切换可恢复。 |
| P2-02 热区 | 四边、起止、厚度、偏移、延迟和边界精度，重叠优先级可复现。 |
| P2-03 多屏 | 两屏不同偏移与 DPI 的配置独立，实屏枚举和跨屏结果分别记录。 |
| P2-04 窗口避让 | 普通、最大化、无边框、Shell 独占信号、未知以及应用例外走对应结果。用独立窗口测 Win32 信号，游戏和视频分别验收。 |
| P2-05 系统快捷键 | 录入、清空、恢复默认、重复检测、系统冲突、失败回滚和释放。实际键盘投递与自动调用分别验收。 |
| P2-06 收起规则 | 临时显示、锁定、暂停、离开整组区域计时、重新进入取消、外部点击和分层 Esc。 |
| P2-07 兼容与性能 | P1 配置与项目恢复、配置可安全备份、正常模式空闲 CPU/工作集、误触发和原生调用日志。 |

P3 分组功能留待用户确认。P2 为菜单和后续交互面板提供共享命中路径。
