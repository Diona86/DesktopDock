## 验收结果

| 项目 | 实测证据与边界 |
| --- | --- |
| 两级结构和创建 | 保存一级和二级分组，验证第二层可接收项目、第三层和环路拒绝，失败时配置字节不变。Dock 图标中心的放置命中创建新组，图标边缘仍用于排序。UI 在 Dock 背景及一级分组提供右键创建入口。 |
| 编辑、移入和移出 | 实际应用状态验证重命名、独立图标和展开方向。覆盖两级之间移动、跨组移动、回到 Dock、组内项目排序和根分组排序。重启后有序树和布局一致。 |
| 删除和引用安全 | 实际 WPF 对话框显示子项目及子分组数量。两种选择均未预选，确认按钮初始禁用，取消后配置原字节一致。另执行上移内容和移除内部引用，验证上移保留顺序、子组及引用，删除引用后目标文件和自定义图标的 SHA-256 一致。 [删除对话框证据](p3-evidence/delete-ui.log) |
| Dock 布局 | 运行中读取实际行列与视口，检查单行、单列、多行网格、多列网格和分组展开。实际验证设置图标可见上限后视口滚动且条目仍存在。分组展开布局在 Dock 显示时展开首个一级组。 |
| 展开布局及动画 | 检查四种 WPF 面板布局的真实条目矩形和截图。扇形坐标形成弧线，横向及纵向坐标各按对应轴排列。各模式观测到 170 ms 动画的过渡透明度与结束状态。动画遵循系统动画设置。 [面板独立检查](p3-evidence/panels.log) |
| 返回、Esc 和自动隐藏 | 两层面板各有实际 HWND。先关右键菜单，再逐层关闭面板。返回与空白关闭可用。按原生窗口矩形提交 Dock、面板及 14 px 间隙的受控指针样本，超过收起延迟仍显示。离开全部区域后按延迟收起。 |
| 配置兼容 | 实际从旧配置读取条目。版本 1 和 2 首次保存到版本 3 时保留逐字节一致的原始备份。保留原始项目标识和顺序。 |

拖放在 MCP 中驱动同一应用内命中与提交代码。Esc、返回、空白点击和区间移动使用受控事件与坐标。物理鼠标、系统 OLE 拖放消息和拖拽滚动端到端留待单独实测。P2 的双物理屏和游戏场景补测继续记录于 TODO。
