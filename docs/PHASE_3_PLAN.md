# Desktop Dock 阶段 3 计划

P3 从 P2 提交 `726520c` 开始。继续使用 WPF、.NET 10、独立配置和应用内 MCP。保留 P1 项目引用、P2 显隐与避让入口，在其上实现两级分组和布局。

1. 增加分组资料和统一的有序层级条目。分组和项目共享稳定标识，保存时验证父级存在、深度和排序。配置版本升至 3，读取版本 1 与 2，首次写入时原子备份旧文件。
2. Dock 混合显示项目与分组。图标边缘用于排序，中心用于合并两个项目或放入分组。分组面板让项目能移到其他组、上一级或 Dock。删除分组提供上移内容、移除引用和取消三种路径。
3. 分组默认网格，可分别设置扇形、横向、纵向和展开方向。Dock 提供自动、单行、单列、多行、多列和分组展开布局。最大可见图标数限制视口，剩余图标可滚动访问。图标尺寸复用原外观设置。
4. 展开面板加入 P2 交互命中区，鼠标在相邻窗口与桥接间隙移动时保持显示。Esc 优先关菜单，再按从内到外关闭分组。设置动作使用受控窗口和真实保存路径。
5. 用 MCP 验证有序树持久化、分组资料、放置与排序、配置迁移、真实面板渲染和动画、显隐交互、两种删除结果与原文件哈希。独立标出未执行的实体鼠标与 OLE 事件路由。

| 验收项 | 通过判据 |
| --- | --- |
| P3-01 层级与创建 | 右键入口及合并路由可创建分组。二级可接收项目，第三层被拒绝且配置不变。 |
| P3-02 管理与移动 | 名称、图标、展开选项可编辑。项目能跨组、移入、移出。分组与组内顺序重启后相同。 |
| P3-03 引用安全 | 删除明确选择上移或移除。前者保留内部引用与次序，后者仅移除对应引用。原文件路径和 SHA-256 一致。 |
| P3-04 布局与动画 | Dock 布局和四种面板使用真实 WPF 渲染进行检查。图标数上限、间距、方向和动画有可观察证据。 |
| P3-05 显隐交互 | 两层 Esc、返回与空白关闭正确。Dock、面板及相邻间隙不因收起延迟意外隐藏。 |
| P3-06 兼容性 | P1、P2 自动回归通过，旧配置备份完整，P4 等待确认。 |
