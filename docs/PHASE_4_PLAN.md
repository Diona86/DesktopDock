# Desktop Dock 阶段 4 计划

P4 为现有 Windows Dock 加入可编辑主题。P3 的项目、自由网格、分组与热区配置继续由原有配置管理。独立显示器上的多个实际 Dock 窗口属于 P5。P4 用稳定 Dock 标识保存独立覆盖，并在当前窗口和隔离测试配置验证合并规则。

| 工作 | 实施与验收 |
| --- | --- |
| 主题模型 | 建立极简、玻璃、科技主题，材质、颜色、圆角、边框、阴影、尺寸、提示、手柄、反馈和动画声明式保存。可修改布局预设，保留自由网格中的项目与位置。 |
| WPF 渲染 | Dock 与分组面板共享视觉参数。检查三套主题的真实截图、元素矩形、提示及手柄。验证快速连续呼出与收起、全局动画开关及系统减少动画偏好。 |
| 编辑器 | 从设置或通知区域打开主题编辑器。左侧导航、中间预览、右侧调参。用真实 Dock 和编辑器验证修改、撤销、恢复默认、保存、另存、取消恢复。 |
| 覆盖规则 | 默认继承全局。验证修改全局后局部参数仍存在，当前 Dock 可选独立主题，也可恢复继承。 |
| 主题文件 | 版本化声明式格式。写入前检查字段、数值、类型和资源大小。实际测试成功回读，以及畸形、越界、路径和可执行负载拒绝。拒绝前后比较配置文件。 |
| 性能 | 在性能模式减少材质效果和动画。实际检查资源状态与重复切换时延；记录单机测量范围。 |
| 交付 | 构建 Windows x64 自包含版，复跑 P1、P2、P3，更新验收、README 和 TODO，结束在 P4。 |

透明窗口继续使用 P3 的分层 WPF HWND。优先对应用自绘材质层做模糊，保持图标与文字清晰。旧 DWM 模糊接口从 Windows 8 起无法产生原有模糊。 [Microsoft DWM 文档](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmenableblurbehindwindow)
