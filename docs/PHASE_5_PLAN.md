# Desktop Dock 阶段 5 计划

P5 将 Dock 配置关联到稳定显示器标识，并交付屏幕热区编辑、桌面图标恢复、托盘和登录启动。此前单屏配置随原显示器保留，断开仅释放对应窗口。安装包进入 P6，本阶段提供便携版的启动项清理入口。

| 验收项 | 实施与验证 |
| --- | --- |
| 多屏窗口 | 每个连接屏有独立 WPF 窗口和配置。比较位置、主题、布局、热区、锁定及原生窗口矩形。变更主屏、负坐标、DPI、分辨率、断开与重连时核对同一档案及磁盘内容。 |
| 热区地图 | 同比例绘制全部显示器、Dock 与热区，拖动端点、厚度和偏移。实际验证添加、删除、重叠提示和保存。 |
| 桌面图标 | 优先使用可读取和核对的 Windows Shell 状态。确认后才能隐藏。写入恢复记录、核对当前状态和 Explorer 代际。实际会话未获得单独的隐藏确认时，只读验证原生接口，并在隔离后端复测更改、手工覆盖、重启和中断。 |
| 托盘与快捷键 | 显示、隐藏、热区暂停和恢复、设置、图标恢复、退出都进入同一业务路径。验证恢复快捷键注册、退出清理和冲突提示。 |
| 登录启动 | 由用户启停，检测当前用户注册状态，重复启用保持一个条目，便携卸载入口仅清理所拥有的启动项。验证注册表操作使用专用测试键，另记录实际登录与设备复测边界。 |
| 回归和发布 | 构建 Windows x64 自包含包，复跑此前适用的 P1–P4 自动化，更新验收、README 和 TODO。 |

桌面图标隐藏前应通过产品对话框确认。手动恢复入口为桌面右键「查看 → 显示桌面图标」。登录启动使用当前用户的 Run 项。 [Windows Run 项文档](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)
