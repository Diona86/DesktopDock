# Desktop Dock 1.0.0 发布计划

目标平台为 Windows 11 x64。安装、配置保护和验收均使用独立测试目录与临时数据。运行中的真实 Explorer 与用户原有启动项保持由用户控制。

| 工作 | 验收证据 |
| --- | --- |
| 安装和卸载 | 构建正式安装包。检查安装目录、快捷方式、用户级登录启动选项、卸载入口和默认保留配置。使用隔离档案检查明确选择清理与保留用户目标文件。 |
| 升级 | 检查程序版本和各档案兼容性，写入可验证的升级前备份，验证旧配置迁移、未来版本拒绝和恢复步骤。 |
| 综合回归 | 复跑 P1–P5 的实际 WPF、Win32 和隔离故障用例，记录实体设备与受控验证的边界。 |
| 性能 | 采集新进程启动、CPU、内存、热区到显示、图标加载、主题切换、不同 Dock 数量以及持续运行样本。报告指标口径、环境和实际样本时长。 |
| 交付 | 提供安装包、Windows x64 便携包、源码归档、构建与使用说明、版本记录、校验值、完整测试报告和已知问题。 |

本机能验证真实 Windows 应用、安装器和隔离故障。物理多屏、真实 Explorer 图标变更与重启、登录触发和其他需要现场设备或隔离系统的场景分别记录。
