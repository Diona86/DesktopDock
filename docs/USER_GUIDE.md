# 使用 Desktop Dock

## 项目和分组

在「设置 → 项目管理」点「添加应用」，可选择 EXE 程序或 LNK 快捷方式。也可选「文件资源管理器」，直接把 Windows 自带的文件资源管理器加入当前 Dock。

右键 Dock 的空白处，选择「新建」以打开 Windows 的新建菜单。系统提供当前可用的项目类型，并将新建内容放到桌面。可在桌面重命名。要让它显示在 Dock 中，可从桌面拖入，或在「项目管理」中添加。

- 通过「项目管理」添加 EXE、LNK、文件、文件夹或 HTTP/HTTPS 网址，也可从资源管理器拖入。单击图标打开目标。右键可改名称、路径和图标，或移除 Dock 引用。
- 拖到普通图标中心可合并分组，拖到边缘可排序。右键空白或一级分组可创建分组。删除分组时选择保留内容并上移，或移除组内引用。
- 拖 Dock 边缘或四角调整自由网格，松手时对齐整格。图标可移动到空格。悬停图标后拖右下角手柄改变占格。移动整个 Dock 使用空白处的移动手柄。

## 显示、主题和多屏

在「设置 → Dock 外观」选择「图标名称」。可以在图标下方显示、悬停时显示或不显示。此设置也适用于分组内的图标，每个 Dock 可独立保存。现有配置默认继续在悬停时显示名称。

- 「热区与行为」可切换常驻和自动隐藏。地图可调整热区范围、厚度、偏移和延时，改完应用到当前屏。窗口避让规则和快捷键在设置中编辑。
- 主题编辑器支持极简、玻璃和科技。可以预览、撤销、保存、另存为或取消。选择当前 Dock 可独立覆盖参数。主题交换使用 `.docktheme` 文件。
- 设置左栏选择显示器。显示器断开时保留该档案。显示器驱动改变设备标识后，可能需要重新配置屏幕归属。

## 软件更新

通过托盘打开「设置 → 通用设置 → 软件更新」，点击「检查更新」。从 1.4.0 起，使用默认配置目录的 Windows 安装版可在发现新版后点击「一键更新」。下载期间可取消。校验通过后，Desktop Dock 会退出，安装器会检查并备份现有配置、升级原安装目录，成功后重新打开设置。

旧版需要先手动安装 1.4.0 才能使用此按钮。便携版或使用自定义配置目录的副本，可通过发行页下载。已下载的更新使用 GitHub 发行中的 SHA-256 校验。 [GitHub Releases](https://github.com/Diona86/DesktopDock/releases) · [安装和配置恢复](INSTALLATION.md)

## 常见问题

**Dock 没出现。** 在任务栏通知区域选择「显示全部 Dock」。自动隐藏时检查热区暂停状态和窗口避让规则。

**移动文件后图标打不开。** 右键 Dock 项目选「编辑」，重新选择目标路径。移除引用会保留源文件。

**桌面图标如何手动恢复？** 在桌面空白处右键「查看 → 显示桌面图标」。如果已经勾选，先取消再重新勾选。系统图标的逐项选择在 Windows「主题 → 桌面图标设置」。

**如何导出排查信息？** 在「通用设置」选择「导出诊断」，保存为一个新 JSON 文件。诊断包含版本、窗口行为、显示器尺寸与缩放及简要事件。导出前可核对保存位置，分享前可打开文件检查内容。目标路径和文件内容都不在这份导出中。

**配置提示不兼容。** 保留原文件，参照 [备份与恢复](INSTALLATION.md#备份与恢复) 核对版本，再使用相应的备份恢复。
